# 2026-09-16 Tiny Week Development Log

## Work Summary

아이폰의 세로 화면 방향 고정을 해제하지 않고도 Tiny Week를 가로 레이아웃으로 볼 수 있도록 앱 내부 회전 기능을 추가했다. 시스템 방향 설정은 웹앱에서 변경할 수 없으므로, 세로 뷰포트 안에서 앱 화면 전체를 90도로 회전하는 방식으로 구현했다.

## Work Completed

- 세로 화면 안내에 `가로로 보기` 버튼과 사용 방법을 추가했다.
- 회전 선택을 로컬 저장소에 기록해 다음 실행부터 자동으로 적용되도록 했다.
- 회전된 주간 화면에서 설정을 해제할 수 있는 `회전 해제` 버튼을 추가했다.
- 주간 화면과 식단·영화 모달을 하나의 회전 컨테이너에 배치해 기존 기능이 같은 방향으로 표시되도록 했다.
- 정적 파일 변경이 설치형 PWA에 반영되도록 서비스 워커 캐시 이름을 `tiny-week-v9`로 갱신했다.

## Decisions

- 아이폰의 시스템 세로 방향 고정은 웹앱에서 제어할 수 없으므로 CSS 화면 회전을 사용했다.
- 앱을 보는 사용 빈도가 입력 빈도보다 높다는 실제 사용 방식을 우선해, 이번 작업에서는 읽기와 기본 조작을 먼저 개선하고 키보드 방향 최적화는 후속 작업으로 남겼다.
- 기존 가로 레이아웃, 데이터 저장 구조, 식단·영화 편집 동작은 변경하지 않았다.

## Current Status

코드 구현과 데스크톱 Chrome 기반 렌더링 검증을 완료했다. 390×844 및 360×780 세로 뷰포트에서 최초 안내, 회전 활성화, 선택 기억, 새로고침 후 자동 적용, 주간 이동, 식단 모달, 회전 해제가 동작했으며 화면 넘침은 발생하지 않았다. 844×390 및 780×360 가로 뷰포트에서도 기존 7일 레이아웃이 유지됐다. Playwright 번들 브라우저가 설치되어 있지 않아 이미 설치된 Chrome을 사용했다.

작업 폴더에 기존부터 `data/voidmoon/2027.json` 삭제 변경이 있어, 서비스 워커 검증은 해당 파일과 조회 대상 연도 파일을 임시 테스트 복사본에 보충한 뒤 진행했다. 실제 아이폰 홈 화면 PWA와 iOS 키보드는 아직 확인하지 않았다.

## Next Steps

- 실제 아이폰 홈 화면 PWA에서 회전 방향, 안전 영역, 터치 동작을 최종 확인한다.
- 영화 입력 시 표시되는 iOS 키보드 방향과 사용성을 추후 확인한다.
