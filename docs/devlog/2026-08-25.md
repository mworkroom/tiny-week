# 2026-08-25 Tiny Week Development Log

## Work Summary

기존 주간 프레임 크기와 무스크롤 구성을 유지하면서, 날짜별 영화 영역을 두 개의 독립 입력 슬롯으로 분할했다.

## Work Completed

- 영화 영역의 높이를 변경하지 않고 위아래 두 칸으로 나눴다.
- 각 영화 슬롯을 독립적으로 추가, 수정, 삭제할 수 있도록 입력 대상을 구분했다.
- 기존 단일 `movie` 저장값을 첫 번째 슬롯으로 읽고, 수정 시 두 칸을 지원하는 `movies` 배열로 전환하도록 호환 처리를 추가했다.
- 긴 영화 제목은 기존처럼 말줄임표로 처리해 칸 너비와 전체 프레임을 넘지 않게 했다.

## Decisions

- 전체 프레임과 식단·보이드문 영역은 변경하지 않고 영화 영역 내부만 분할해 기존 아이폰 가로 화면의 비율을 보존했다.
- 두 영화의 시간과 제목을 한 줄에 배치해, 절반으로 줄어든 슬롯 높이에서도 내용을 확인할 수 있게 했다.

## Current Status

구현과 검증을 완료했다. 844×390 가로 뷰포트에서 영화 1·2의 입력과 저장을 확인했고, 문서와 본문의 스크롤 크기가 뷰포트와 일치해 가로·세로 오버플로가 없었다. 브라우저 콘솔 경고와 오류도 발생하지 않았다.

## Next Steps

- 실제 아이폰 홈 화면 앱에서 안전 영역을 포함한 최종 체감 크기를 확인한다.

## Work Summary - 오늘 칸 Void Moon 배지 배경 복구

오늘 날짜 칸에서 Void Moon 시간 글자는 보이지만 배지 배경색이 사라지는 레이어 순서 문제를 수정했다.

## Work Completed - 오늘 칸 Void Moon 배지 배경 복구

- `.void-cell`에 독립 stacking context를 적용해 음수 z-index의 배지 배경이 오늘 칸 배경 뒤로 빠지지 않도록 했다.
- 배지의 기존 크기, 색상, 시간 텍스트와 오늘 칸 배경색은 그대로 유지했다.

## Decisions - 오늘 칸 Void Moon 배지 배경 복구

- 가상 요소의 z-index나 텍스트 레이어를 별도로 재구성하지 않고, 배지 셀 내부에서만 레이어 범위를 격리하는 최소 CSS 수정으로 해결했다.

## Current Status - 오늘 칸 Void Moon 배지 배경 복구
