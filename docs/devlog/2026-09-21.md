# 2026-09-21 Tiny Week Development Log

## Work Summary

회전 버튼을 배포한 뒤에도 아이폰에 이전 화면이 남는 문제를 진단하고 PWA 업데이트를 막는 누락 파일을 복구했다.

## Work Completed

- 로컬 `main`과 `origin/main`이 회전 기능 커밋 `e9d5e18`에서 일치함을 확인했다.
- 공개 페이지의 HTML에는 회전 버튼이 있지만, 서비스 워커의 필수 캐시 목록에 있는 `data/voidmoon/2027.json` 공개 URL은 404인 점을 확인했다.
- 회전 기능 커밋에서 함께 삭제된 2027년 공백의 달 데이터를 이전 커밋의 내용 그대로 복구했다.
- 서비스 워커 캐시 이름을 `tiny-week-v10`으로 변경해 새 워커의 설치와 기존 캐시 교체를 다시 시도하도록 했다.

## Decisions

- `cache.addAll()`은 목록 중 한 파일이라도 404이면 설치가 실패한다. 기존 `v9` 서비스 워커가 설치되지 않아 이전 캐시가 계속 제공되는 것이 배포 누락처럼 보인 주된 원인으로 판단했다.
- 2027년 데이터는 앱의 연도별 조회에도 사용되므로 캐시 목록에서 빼는 대신 파일을 복구했다.

## Current Status

로컬 수정과 데스크톱 Chrome 검증을 완료했다. 390×844 세로 뷰포트에서 서비스 워커 `tiny-week-v10`이 설치·제어 중인 상태, HTML과 2027년 데이터의 캐시 저장, `가로로 보기` 버튼 표시를 확인했다. 공개 사이트는 아직 수정 전 배포 상태이며, 실제 아이폰에서의 갱신은 새 버전 배포 후 확인이 필요하다. 앱은 현재 연도의 전후 연도 데이터를 조회하므로 2025년 데이터 요청에서는 기존과 같은 404가 발생했지만, 그 파일은 서비스 워커의 필수 캐시 목록에 없어 설치에는 영향을 주지 않았다.
